# 🏥 Patient CRM - Healthcare Management System

A simple, fast and user-friendly Patient Management System built with Python and Streamlit for small clinics and hospitals to manage patient records digitally.

This project helps to replace manual paper records with a clean web dashboard where staff can add patients, search records, track recovery status, and view disease-wise analytics in real-time.

## ✨ Features
- 📋 Add new patients with Name, Age, Disease, Phone and Status
- 🔍 Search any patient instantly by name
- 📊 Live Dashboard: Total Patients, Active Cases and Recovered Cases
- 📈 Disease-wise patient count with Bar Chart
- 💾 Data stored in simple CSV files

## 🛠️ Tech Stack
- Python, Streamlit, Pandas, CSV Files, VS Code
